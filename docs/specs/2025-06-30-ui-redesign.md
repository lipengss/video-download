# VideoDL Pro UI 重构设计文档

## 设计方向

- **布局**: 单列流式 — 输入固定顶，预览垂直居中，记录独立滚动
- **视觉**: 工业工具 — 暗黑底(#0d0d0d) + 琥珀强调(#f0a040) + 等宽数据

## 窗口结构

```
┌─ Header (固定) ────────────────────┐
│ VideoDL                          ⚙ │
├────────────────────────────────────┤
│ ┌ Input Row ─────────────────────┐ │
│ │ [URL.........................] │ │
│ └────────────────────────────────┘ │
│  B站 · 抖音 · IG · YT (小字灰)    │
├────────────────────────────────────┤
│                                    │
│     ┌ Preview Card (居中) ────┐    │
│     │ [thumb] platform·title  │    │
│     │ meta · formats · [下载] │    │
│     └─────────────────────────┘    │
│                                    │
├─ Record Section (独立滚动) ────────┤
│ [下载记录 | 本地文件]    📂 🗑     │
│ [全部] [B站2] [抖音1] [IG1]       │
│ ● xxx.mp4 · 1080p · ✓已下载       │
│ ● yyy.mp4 · 720p · 待下载         │
└────────────────────────────────────┘
```

## 关键规则

1. 窗口高度固定，分为三段：header(固定) + 内容区(flex-1) + 记录区(独立overflow-y)
2. 预览卡片在剩余空间垂直居中(justify-center)
3. 记录区 max-height 限制，内部 scroll
4. 平台图标行融入 input 下方，单行小字灰色
5. 设置只通过右上齿轮打开 Dialog
6. Cookies 错误时才显示提示行（input下方）
7. 历史去重 + 本地文件匹配 + 平台分类筛选
8. 操作按钮 hover 出现，默认隐藏
